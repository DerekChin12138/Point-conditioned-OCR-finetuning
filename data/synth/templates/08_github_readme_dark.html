point-conditioned-ocr-finetuning

Fine-tune OvisOCR2 so a magenta crosshair selects one semantic Markdown block instead of dumping the whole page.

Install

uv sync --extra dev --extra synth
uv run playwright install chromium

Build synth data

uv run python data/scripts/build_synth_batch.py --out data/processed/synth --noise

Prefer synthetic HTML with data-block-id attributes; labels come from the same source as the render.
