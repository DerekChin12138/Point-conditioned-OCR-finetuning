Document parsing

Document parsing
Type: Information extraction
Related: OCR, Layout analysis

Document parsing is the conversion of page images or born-digital files into structured text such as Markdown or HTML.

Pipeline systems separate detection, recognition and reading-order assembly, while end-to-end models map pixels directly to markup.

Point conditioning

Point conditioning adds a user-specified location so the model returns only the enclosing semantic block.

This is useful for hover-to-translate and selective copy workflows on dense screenshots.
