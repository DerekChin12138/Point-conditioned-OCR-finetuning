sample_points_in_block

Draws R interest points inside a box with optional center bias. Used to expand one page into many POINT pairs.

Returns objects with kind positive and the owning block_id.

# excerpt
def sample_points_in_block(box, *, n=3, center_bias=0.65):
    points = []
    for _ in range(n):
        x, y = draw_point(box, center_bias)
        points.append((x, y))
    return points
