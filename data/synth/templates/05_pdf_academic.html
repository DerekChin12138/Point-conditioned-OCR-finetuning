Point-Conditioned Block Transcription for Compact Document Parsers

A. Researcher and B. Engineer

Abstract

We study supervised fine-tuning of a page-level parser so that a visual crosshair selects a single semantic block. Synthetic pages provide aligned boxes and Markdown from one HTML source. Real screenshots can be labeled via crop OCR.

1  Introduction

End-to-end document models emit full-page Markdown in reading order. Interactive translation, however, often needs only the block under a cursor.

Zero-shot prompting rarely prevents over-extraction. We therefore construct multi-point supervision inside each block bounding box.

2  Method

Let \(c\) denote the crosshair coordinate and \(B_i\) the \(i\)-th block region. The target is the Markdown of the unique block containing \(c\), or empty if none.

\( y^* = M(B_{i^*}),\quad i^*=\arg\min_i\{\mathbf{1}[c\in B_i]\} \)

Negative points on margins and chrome map to the empty string, teaching the model to abstain.
