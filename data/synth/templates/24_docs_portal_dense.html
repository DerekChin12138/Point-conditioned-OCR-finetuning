Building information-dense training pages

Sparse cards on empty backgrounds teach the wrong prior. Prefer portals, IDE chrome, and stacked windows that fill the viewport with competing text.

Text-tight boxes

Measure glyph ink via Range#getClientRects, not the full-width block box.

Occlusion

Stacked windows hide content; only supervise visible labeled nodes.

Negatives

Docks, title bars, wallpaper, and gutters map to empty strings.

Noise

JPEG and mild rescale approximate screen capture artifacts.

Sampling recipe

For each visible block, draw R∈[2,5] points with strong center bias inside the ink box. Short left-aligned headings no longer receive points in the empty right half of the line box.

Desktop templates set data-capture="viewport" so Playwright grabs a fixed 1440×900 workstation frame instead of a tall sparse scroll.
